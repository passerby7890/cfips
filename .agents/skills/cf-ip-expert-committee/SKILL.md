# Cloudflare 三網優選六人專家委員會 (cf-ip-expert-committee)

本技能定義了 Cloudflare 三網優選 IP 自動化雲端生成系統的六人專家審查與全自動紅隊自測自癒閉環機制。

## 1. 六人專家委員會成員職責

### 1. @DecisionMaker (強決策官 / 總架構師)
- **職責**：統籌全局架構與決策裁決。
- **核心鐵律**：
  - 嚴格落實「只信大陸境內實測指標與黃金 `/24` 直連白名單，嚴禁海外美國 Runner 盲猜延遲與頻寬」。
  - 控管版本發布流程，每次迭代必須完整記錄 `VERSION`、`CHANGELOG.md` 與 `DEV_NOTES.md`。

### 2. @BGP_Architect (跨境 BGP 路由專家)
- **職責**：掌控電信 (CT)、聯通 (CU)、移動 (CM) 國際出口與 Cloudflare Anycast/Unicast 路由特性。
- **核心鐵律**：
  - **嚴格零容忍黑名單**：徹底封殺 `104.18.0.0/15`, `104.20.0.0/15`, `104.21.0.0/16`, `104.22.0.0/16`, `172.66.0.0/16`, `172.67.0.0/16` 等普通繞美高延遲、高丟包網段。
  - **三網專屬 Tier S 亞太直連神仙網段矩陣**：
    - **CT (電信)**：`108.162.192.0/18`, `162.159.192.0/21`, `141.101.114.0/23`, `198.41.208.0/20`, `172.64.32.0/20`, `103.21.244.0/22`, `103.22.200.0/22`
    - **CU (聯通)**：`108.162.192.0/18`, `162.159.128.0/18`, `141.101.112.0/20`, `104.16.50.0/24`, `104.24.0.0/14`, `103.21.244.0/22`
    - **CM (移動)**：`172.64.0.0/13`, `104.28.0.0/14`, `108.162.192.0/18`, `162.158.0.0/15`, `198.41.128.0/17`, `103.21.244.0/22`
  - 同 `/24` 網段輸出最多收錄 3 個 IP，防止 QoS 擁塞與公地悲劇。

### 3. @Mainland_Probe (大陸探針與防封鎖專家)
- **職責**：管理大陸境內實測情報源與容災降級。
- **核心鐵律**：
  - 貫通 HostMonit、WeTest、cdtools 等境內實測探針的真實 RTT 與下行速率。
  - 當任何境內 API 網路超時或失效時，自動平滑降級至高品質亞太直連種子庫，確保流程永不中斷。

### 4. @Origin_Verifier (V2bX 回源握手專家)
- **職責**：把關節點與源站的端到端連通性與健康度。
- **核心鐵律**：
  - 目標：`node1.snowcat77.com:2053/ws`。
  - 所有進入輸出名單的 IP 必須 100% 通過 TLS SNI 握手與 HTTP `101 Switching Protocols` WebSocket 升級。
  - 嚴厲剔除 400、403、404、521、522、525 等回源失敗假活節點。

### 5. @QA_RedTeam (紅隊找茬與自癒測試官)
- **職責**：執行 `scripts/self_test_audit.py` 紅隊五大鐵律審計斷言。
- **5 大鐵律**：
  1. **格式與數量**：輸出檔案存在，每行嚴格遵循 `<IP>#<COUNTRY>`，每網至少 10 筆（目標 50 筆）。
  2. **黑名單零容忍**：零個 `104.18.`, `104.20.`, `104.21.`, `104.22.`, `172.66.`。
  3. **同 C 段分散度**：同 `/24` 網段嚴格 <= 3 個 IP。
  4. **防止美國 Runner 洗標籤**：`#US` 標籤比例嚴格 <= 20%。
  5. **實機 101 握手抽檢**：榜首節點必須能成功握手 `101 Switching Protocols`。
  6. **國內延遲合規**：`best_ips.json` 前 10 名節點國內預估延遲必須 <= 95ms。
- **自癒要求**：若審計報錯，強制定位根因並修改代碼，重跑測試直至 100% 通過。

### 6. @DevOps_Release (CI/CD 與版本控管工程師)
- **職責**：GitHub Actions 自動化流程維護與版本發布。
- **核心鐵律**：
  - GitHub Actions 執行 `python main.py` 後，必須強制執行 `python scripts/self_test_audit.py`。
  - 自測失敗時直接中斷（Exit Code 1），嚴禁覆寫與 Push 線上清單。
  - 歸檔版本至 `CHANGELOG.md` 與 `DEV_NOTES.md`，發布 Git Commit & Tag。

## 2. 自動化自測自癒標準作業流程 (SOP)

```
[代碼編寫/更新]
      │
      ▼
[執行管線: python main.py]
      │
      ▼
[紅隊審計: python scripts/self_test_audit.py]
      │
      ├─► ❌ 未通過 ──► [@QA_RedTeam 退回] ──► [定位問題修復代碼] ──► (重新執行管線)
      │
      └─► ✅ 100% 通過 ──► [@DecisionMaker 准許發布] ──► [更新 CHANGELOG/DEV_NOTES] ──► [Git Commit & Push]
```
